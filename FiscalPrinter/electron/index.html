FiscalPrinter

Local app: capture print jobs → fiscalize → print QR receipt on your printer

HTML is only used internally to lay out the fiscal receipt for the printer driver. Users never open HTML files — the app prints silently to the selected local printer.

Training mode — sample invoice + QR

Offline demo only. This never calls the fiscal API, never changes an invoice and never consumes a fiscal counter. Each copy is marked “TRAINING — NOT A VALID FISCAL INVOICE”.
